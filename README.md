# 🍅 뽀모도로 & 할 일

뽀모도로 타이머와 할 일 목록을 함께 쓸 수 있는 단일 HTML 페이지 앱입니다. 별도 설치나 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

```bash
# 예: 기본 브라우저로 열기 (Windows)
start index.html
```

## 기능

- **뽀모도로 타이머**: 집중(25분) / 짧은 휴식(5분) / 긴 휴식(15분) 모드 전환
- **세션 카운트**: 오늘 완료한 집중 세션 수를 자동으로 기록 (자정 기준 초기화)
- **할 일 목록**: 할 일 추가·완료 체크·삭제
- **로컬 저장**: 브라우저의 `localStorage`를 사용해 새로고침 후에도 상태 유지 (사용 불가 시 메모리에 임시 저장)

## 기술 스택

순수 HTML / CSS / JavaScript로 작성되었으며 외부 라이브러리 의존성이 없습니다.
