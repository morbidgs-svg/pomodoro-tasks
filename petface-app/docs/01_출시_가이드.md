## 1단계 · 계정 만들기 👤

| 서비스 | 용도 | 주소 |
|---|---|---|
| Apple Developer Program | 아이폰 앱 출시 | https://developer.apple.com/programs/ |
| Google Play Console | 안드로이드 앱 출시 | https://play.google.com/console |
| Anthropic Console | AI 분석(Claude API) 키 발급 | https://console.anthropic.com |
| Cloudflare | AI 분석 서버 운영 | https://dash.cloudflare.com |
| RevenueCat | 구독 결제 관리 | https://app.revenuecat.com |
| Google AdMob | 광고 수익 | https://admob.google.com |
| Expo(EAS) | 앱 빌드·스토어 제출 | https://expo.dev |

- 사업자로 등록하면 스토어에 판매자명이 회사명으로 표시됩니다. 애플은 사업자 등록 시 D-U-N-S 번호가 필요합니다.
- Anthropic 콘솔에서 **월 지출 한도(spend limit)**를 꼭 설정하세요(예: 첫 달 10만 원).

## 2단계 · 앱 고유 ID 정하기 👤 → ✅

`app.json`의 `com.CHANGE_ME.petface`를 본인 도메인이나 회사명으로 바꿉니다. 예: 쇼핑몰 주소가 `myshop.co.kr`이면 `kr.co.myshop.petface`.
- 한 번 스토어에 올리면 **바꿀 수 없습니다.**
- iOS(`ios.bundleIdentifier`)와 Android(`android.package`) 두 곳 모두 바꿉니다.

## 3단계 · AI 분석 서버 배포 (Cloudflare Workers)

컴퓨터에 Node.js(https://nodejs.org, LTS 버전)를 설치한 뒤, 터미널에서 `server` 폴더로 이동해 실행합니다.

```bash
cd petface-app/server
npm install
npx wrangler login                       # 브라우저에서 Cloudflare 로그인
npx wrangler kv namespace create QUOTA   # 출력된 id를 wrangler.toml의 REPLACE_WITH_KV_NAMESPACE_ID에 붙여넣기
npx wrangler secret put ANTHROPIC_API_KEY      # Anthropic 콘솔에서 발급한 키 입력
npx wrangler secret put REVENUECAT_SECRET_KEY  # 4단계 후 입력(RevenueCat의 Secret API key)
npx wrangler secret put APP_KEY                # 아무 긴 임의 문자열(앱 .env에도 같은 값 입력)
npm run deploy
```
- 배포가 끝나면 `https://petface-api.<계정>.workers.dev` 같은 주소가 나옵니다. 이 주소를 7단계에서 사용합니다.
- 작동 확인: 브라우저에서 `주소/health`를 열어 `{"ok":true}`가 나오면 성공입니다.
- 무료 플랜은 KV 쓰기 한도가 하루 1,000회라 하루 약 250회 분석까지만 가능합니다. 출시 전에 Workers 유료 플랜으로 바꾸세요(비용·수익 분석 문서 3번 참고).
- 사용할 AI 모델은 `wrangler.toml`의 `CLAUDE_MODEL_FREE` / `CLAUDE_MODEL_PREMIUM`에서 정합니다(비용·수익 분석 문서 참고).

## 4단계 · 구독 상품 만들기 👤

1. **App Store Connect**: 앱 등록 → '구독' → 구독 그룹 '펫페이스 프리미엄' → 상품 2개
   - `petface_premium_monthly` (월간), `petface_premium_yearly` (연간)
   - 가격 예: 월 3,900원 / 연 29,000원 (제안값)
   - 애플 **소규모 사업자 프로그램(Small Business Program)**에 가입하면 첫해 수수료가 30%에서 15%로 낮아집니다.
2. **Google Play Console**: 수익 창출 → 구독 → 같은 ID로 상품 2개
3. **RevenueCat**
   - 프로젝트 생성 → iOS 앱·Android 앱 추가(각 스토어 연동 키 입력)
   - Entitlement(권한) 이름: **`premium`** ← 코드와 똑같아야 합니다
   - Offering 'default'에 월간(MONTHLY)·연간(ANNUAL) 패키지 연결
   - API keys에서 **Public SDK key**(iOS용·Android용) → 7단계 .env에 입력
   - **Secret API key** → 3단계 `REVENUECAT_SECRET_KEY`에 입력

## 5단계 · 광고 만들기 (AdMob) 👤

1. AdMob에서 앱 2개(iOS, Android) 등록
2. 광고 단위 만들기: **배너(Banner)** 1개 + **보상형(Rewarded)** 1개를 각 앱마다 만듭니다
3. `app.json`의 `react-native-google-mobile-ads` 부분에 있는 테스트용 앱 ID(`ca-app-pub-3940256099942544~...`)를 **내 AdMob 앱 ID**로 바꿉니다
4. 광고 단위 ID 4개를 7단계 .env에 입력합니다
- 개발 중에는 자동으로 구글 테스트 광고가 나옵니다(실수로 내 광고를 클릭해 계정이 정지되는 것을 방지).
- 이 앱은 **맞춤형 광고를 쓰지 않도록** 설정되어 있어 iOS 추적 허용 팝업(ATT)이 필요 없습니다. 맞춤형 광고로 바꾸면 수익은 늘 수 있지만 ATT 팝업과 개인정보 동의 절차를 추가해야 합니다.

## 6단계 · 개인정보처리방침·이용약관 게시 👤

- `docs/03_개인정보처리방침_초안.md`, `docs/04_이용약관_초안.md`의 [대괄호] 부분을 채워 웹에 게시합니다(쇼핑몰 게시판, 노션 공개 페이지 등).
- 앱스토어와 플레이스토어 모두 **개인정보처리방침 URL이 필수**입니다.
- 법률 문서이므로 출시 전에 전문가 검토를 권장합니다.

## 7단계 · 앱 설정값 입력

`petface-app/.env.example`을 복사해 `.env` 파일을 만들고 값을 채웁니다.

| 항목 | 넣을 값 |
|---|---|
| `EXPO_PUBLIC_API_URL` | 3단계 서버 주소 |
| `EXPO_PUBLIC_APP_KEY` | 3단계 APP_KEY와 같은 값 |
| `EXPO_PUBLIC_REVENUECAT_IOS_KEY` / `_ANDROID_KEY` | 4단계 Public SDK key |
| `EXPO_PUBLIC_ADMOB_*` | 5단계 광고 단위 ID 4개 |
| `EXPO_PUBLIC_PRIVACY_URL` / `_TERMS_URL` | 6단계 주소 |
| `EXPO_PUBLIC_SUPPORT_EMAIL` | 고객 문의 이메일 |

- EAS 클라우드 빌드에서도 같은 값을 쓰려면 expo.dev 프로젝트의 **Environment variables**에 똑같이 등록합니다.
- `.env`는 깃허브에 올라가지 않도록 이미 설정되어 있습니다.

## 8단계 · 테스트 빌드 → 내 폰에서 확인

```bash
cd petface-app
npm install
npx eas-cli@latest login
npx eas-cli@latest build --profile development --platform android   # 안드로이드 테스트용
npx eas-cli@latest build --profile development --platform ios       # 아이폰 테스트용(애플 계정 필요)
```
- 빌드가 끝나면 나오는 QR코드로 폰에 설치합니다.
- 그다음 `npx expo start`를 실행하면 테스트 앱이 연결되어 바로 화면을 확인할 수 있습니다.
- **반드시 확인할 것(체크리스트)**
  - [ ] 고양이·강아지 실제 사진 각각 5장 이상 분석해 결과가 자연스러운지
  - [ ] 반려동물이 아닌 사진(사람, 인형)에서 안내 문구가 나오고 횟수가 차감되지 않는지
  - [ ] 무료 3회 소진 → 보상형 광고 → 1회 추가되는지
  - [ ] 샌드박스 계정으로 구독 결제 → 광고가 사라지고 기록 그래프가 열리는지
  - [ ] 앱 삭제 후 재설치 → '구매 복원'으로 프리미엄이 돌아오는지
  - [ ] 공유하기로 카카오톡·인스타그램에 결과 이미지가 올라가는지
  - [ ] 한국어/영어/일본어 전환

> 참고: 서버 주소를 비워 둔 개발용 빌드에서는 **데모 모드**로 예시 결과가 나옵니다(AI 비용이 들지 않음). 출시용 빌드에서는 데모 모드가 꺼집니다.

## 9단계 · 스토어 등록 정보 준비

- 앱 이름·설명·키워드: `docs/05_스토어_등록문구.md` (한·영·일)
- 스크린샷: 아이폰 6.9인치(1320×2868 또는 1290×2796) 3~10장, 안드로이드 폰 2~8장 (정확한 규격은 제출 화면에서 다시 확인)
  - 실제 반려동물 사진으로 결과 화면을 캡처해 쓰는 것을 권장합니다.
- **App Store 개인정보 라벨(App Privacy)** 응답 예시
  - 사진: 수집함 → 앱 기능에 사용, 사용자와 연결되지 않음, 추적에 사용하지 않음
  - 구매 내역: 수집함(RevenueCat) → 앱 기능
  - 기기 ID: 수집함 → 앱 기능(무료 횟수 관리), 광고(AdMob)
  - 광고 데이터: AdMob SDK가 수집 → 제3자 광고, 추적하지 않음(비맞춤형)
- **Google Play 데이터 보안 양식**도 위와 같은 내용으로 작성합니다.
- 연령 등급: 전체이용가 수준(폭력·선정성 없음)

## 10단계 · 심사 제출

```bash
npx eas-cli@latest build --profile production --platform all
npx eas-cli@latest submit --platform ios
npx eas-cli@latest submit --platform android
```

| 구독 화면에 자동 갱신 안내·약관·개인정보 링크 | ✅ (6단계 URL을 입력해야 링크가 보입니다) |

## 출시 후 운영 팁
- **추천 상품 바꾸기**: `src/config/products.ts`만 고치면 됩니다(`docs/06_추천상품_등록방법.md`). 반영하려면 앱 업데이트가 필요합니다.
- **AI 지시문 수정**: `server/src/prompt.ts`를 고치고 `npm run deploy`만 하면 앱 업데이트 없이 바로 반영됩니다.
- **무료 횟수·한도 조정**: `server/wrangler.toml`의 값을 바꾸고 `npm run deploy`.
- 매주 Anthropic 콘솔에서 비용을, RevenueCat에서 구독 매출을 확인하세요.
