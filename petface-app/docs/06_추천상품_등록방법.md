# 추천 상품 등록 방법 (쇼핑몰·제휴 링크 연결)

수정할 파일은 **`src/config/products.ts` 하나**입니다.

## 1. 상품 하나의 구조
```ts
{
  id: "myshop-feather-wand",                 // 겹치지 않는 영문 ID
  title: { ko: "깃털 낚싯대", en: "Feather wand", ja: "猫じゃらし" },
  url: "https://내쇼핑몰.com/product/123",   // 상품 페이지 주소
  imageUrl: "https://내쇼핑몰.com/img/123.jpg", // 선택: 상품 이미지 주소(정사각형 권장)
  priceText: { ko: "9,900원" },              // 선택: 가격 표시
  source: "myshop",                          // 내 쇼핑몰이면 "myshop", 쿠팡파트너스 등은 "affiliate"
  species: ["cat"],                          // "cat", "dog" 또는 둘 다 ["cat", "dog"]
  categories: ["toy"],                       // 아래 카테고리 표 참고(여러 개 가능)
},
```

## 2. 카테고리 (AI가 결과에 따라 이 중 최대 3개를 골라 줍니다)
| 코드 | 의미 | 주로 추천되는 상황 |
|---|---|---|
| toy | 장난감 | 심심함, 놀고 싶음 |
| chew | 껌·씹는 장난감(강아지) | 스트레스 해소, 치아 관리 |
| scratcher | 스크래쳐(고양이) | 스트레스, 영역 표시 |
| treat | 간식 | 보상, 기분 전환 |
| calming | 안정·진정 용품 | 불안, 무서움 |
| bed | 쿠션·하우스 | 피곤함, 휴식 |
| grooming | 그루밍 | 털·피부, 눈물 자국 |
| dental | 덴탈 케어 | 치석, 입 냄새 |
| water | 급수기 | 음수량 관리 |
| walk | 산책 용품(강아지) | 활동량 부족 |
| health_check | 건강 체크 | 이상 신호가 있을 때 |

## 3. 노출 규칙
- 결과 화면: AI가 고른 카테고리와 맞고 반려동물 종류가 맞는 상품을 **최대 4개**, 내 쇼핑몰 상품을 먼저 보여 줍니다.
- 추천템 탭: 전체 상품을 보여 주고, 최근 결과와 맞는 카테고리에는 ⭐ 표시를 합니다.
- `url`이 비어 있는 상품은 출시용 앱에서 **자동으로 숨겨집니다**(개발용 앱에서는 SAMPLE 표시로 보임).
- `source: "affiliate"` 상품이 화면에 있으면 제휴 수수료 안내 문구가 자동으로 표시됩니다.

## 4. 쿠팡파트너스 사용 시 주의
- 링크는 쿠팡파트너스에서 발급한 **단축 링크(파트너스 링크)**를 그대로 넣습니다.
- 앱에 표시되는 안내 문구: "이 화면의 일부 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
  - 블로그 등에서는 "이 포스팅은 쿠팡 파트너스 활동의 일환으로…" 문구가 널리 쓰입니다. **앱 화면에 표기하는 방식은 공식 기준을 확인하지 못했습니다.** 쿠팡파트너스 운영 정책과 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」을 확인하고 필요하면 문구(`src/locales/ko.ts`의 `affiliateDisclosure`)를 수정하세요.
- 쿠팡파트너스 정책상 앱 안에서 링크를 사용해도 되는지 사전에 확인하세요(확인하지 못했습니다).

## 5. 수정 후 반영
상품 목록은 앱 안에 들어 있으므로 **앱 업데이트(새 빌드 제출)가 필요합니다.** 자주 바꿀 계획이라면, 상품 목록을 서버에서 받아오도록 바꾸는 개선을 다음 단계로 검토하세요.
