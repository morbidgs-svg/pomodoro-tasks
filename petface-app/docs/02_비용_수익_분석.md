## 2. AI 분석 1회당 비용

### 2-1. 요금표 [확인]
출처: Claude API 공식 요금(Claude API 개발 도구에 내장된 요금표, 2026-10-06 기준)

| 모델 | 입력 100만 토큰당 | 출력 100만 토큰당 | 특징 |
|---|---|---|---|
| Claude Opus 5.5 | $4.00 | $20.00 | 가장 정교함(현재 기본값) |
| Claude Sonnet 5.5 | $2.00 | $10.00 | 품질과 비용의 균형 |
| Claude Haiku 5.5 | $0.10 | $0.50 | 매우 저렴. 단, 거절 시 자동 대체 기능은 없음 |

※ Haiku 5.5 요금은 입력이 10만 토큰 이하일 때 기준입니다. 펫페이스 요청은 약 3,400토큰이라 해당됩니다.

### 2-2. 요청 1회의 토큰 양
| 구성 | 토큰 | 근거 |
|---|---|---|
| 사진(1024×1024로 줄여서 전송) | 약 1,430 | **[계산]** 공식 공식 '가로×세로÷750'(28px 단위로 맞춤) |
| AI 지시문(분석 기준) | 약 1,400 | **[추정]** 영어 약 950단어 |
| 결과 형식 정의 등 | 약 500 | **[추정]** |
| **입력 합계** | **약 3,400** | |
| 출력(결과 + AI 내부 사고) | 1,500~3,000 | **[추정]** 한국어·일본어는 영어보다 토큰이 많이 나옵니다 |

### 2-3. 1회당 비용 [계산]
| 모델 | 달러 | 원화(1,400원/$) |
|---|---|---|
| Opus 5.5 | $0.044 ~ $0.074 | **약 61 ~ 103원** |
| Sonnet 5.5 | $0.022 ~ $0.037 | **약 31 ~ 52원** |
| Haiku 5.5 | $0.0011 ~ $0.0018 | **약 1.5 ~ 2.6원** |

### 2-4. 울음소리 분석 1회당 비용 [계산]
울음소리는 녹음 원본 대신 **소리 그림(600×240 이미지, 약 210토큰)**과 숫자 특징을 보냅니다. 그래서 입력이 약 2,700토큰으로 사진보다 조금 적습니다. 입력 토큰 수는 [추정]입니다.

| 모델 | 달러 | 원화(1,400원/$) |
|---|---|---|
| Opus 5.5 | $0.035 ~ $0.061 | **약 49 ~ 85원** |
| Sonnet 5.5 | $0.017 ~ $0.030 | **약 24 ~ 43원** |
| Haiku 5.5 | $0.0009 ~ $0.0015 | **약 1.2 ~ 2.1원** |

- 사진과 소리 분석은 **같은 하루 횟수**를 함께 씁니다(예: 무료 3회 = 사진 2회 + 소리 1회).
- 녹음이 너무 조용하면 휴대폰에서 바로 "잘 안 들려요"라고 안내하고 서버로 보내지 않으므로 비용이 들지 않습니다.

> 출시 전에 실제 사진으로 10~20회 분석한 뒤 Anthropic 콘솔의 사용량 화면에서 실제 단가를 꼭 확인하세요. 위 출력 토큰은 추정치입니다.

## 4. 시나리오별 손익 [계산 + 추정]

### 4-1. 가격 가정 [추정]
- 프리미엄 월 3,900원 / 연 29,000원 (제안값입니다. 경쟁 앱 가격은 조사하지 않았습니다)
- 스토어 수수료 15%를 빼면 월 구독 1명당 **실수령 약 3,315원**

### 4-2. 프리미엄 사용자 1명의 월 AI 비용
| 사용량 | Opus 5.5 (1회 약 82원) | Sonnet 5.5 (약 41원) | Haiku 5.5 (약 2원) |
|---|---|---|---|
| 가벼운 사용: 하루 1회(월 30회) | 2,460원 | 1,230원 | 60원 |
| 보통: 하루 3회(월 90회) | **7,380원 (적자)** | 3,690원 (손익분기 근처) | 180원 |
| 최대 한도: 하루 30회(월 900회) | 73,800원 (큰 적자) | 36,900원 (적자) | 1,800원 |

→ **Opus 5.5를 프리미엄에 쓰려면** 하루 한도를 5~10회로 낮추거나, 가격을 올리는 것을 검토해야 합니다. (`PREMIUM_DAILY_LIMIT` 값 변경. 결제 화면 문구 `paywall.f1`도 함께 수정)

### 4-3. 무료 사용자 1명의 월 AI 비용 (하루 3회를 모두 사용하는 경우)
| Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|
| 약 7,380원 | 약 3,690원 | 약 180원 |

→ 광고 수익만으로 Opus 비용을 메우기는 어렵다고 판단됩니다(광고 단가는 미확인). **무료 사용자에게는 Haiku 5.5를 권장합니다.**

## 5. 모델 결정 전에 할 일 (권장 순서)
1. 서버를 배포한 뒤(출시 가이드 3단계) 같은 사진 20~30장(강아지·고양이 반반, 밝은 사진·어두운 사진 섞어서)을 준비합니다.
2. `CLAUDE_MODEL_FREE`를 바꿔 가며(`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`) 같은 사진을 분석합니다.
3. 기분 판단이 그럴듯한지, 건강 신호를 과장하거나 놓치지 않는지 비교합니다.
4. Anthropic 콘솔에서 실제 비용을 확인한 뒤 무료·프리미엄 모델을 정합니다.

## 6. 비용 폭주 방지 장치 (이미 구현됨)
| 장치 | 기본값 | 설정 위치 |
|---|---|---|
| 무료 1일 분석 | 3회 (+광고 시청 최대 2회) | `FREE_DAILY_LIMIT`, `AD_BONUS_MAX` |
| 프리미엄 1일 분석 | 30회 | `PREMIUM_DAILY_LIMIT` |
| 같은 인터넷 주소(IP) 1일 무료 분석 | 20회 | `IP_DAILY_LIMIT` |
| 서비스 전체 1일 분석 | 5,000회 | `GLOBAL_DAILY_LIMIT` |
| 반려동물이 없는 사진 | 사용자 횟수에서 차감하지 않지만 IP·전체 한도에는 포함 | |

> 추가로 Anthropic 콘솔에서 **월 지출 한도(spend limit)**를 꼭 설정하세요. 위 한도가 뚫려도 최종 안전장치가 됩니다.
