# 펫페이스 (PetFace)

강아지·고양이의 **얼굴 사진**이나 **울음소리**로 **기분 추정 · 컨디션 · 건강 이상 신호 관찰 · 케어 팁 · 상품 추천**을 제공하는 앱입니다.
수익 모델: 프리미엄 구독(RevenueCat) + 광고(AdMob) + 내 쇼핑몰·제휴 상품 추천.

## 구성
```
petface-app/
├─ src/app/            화면(Expo Router)
│  ├─ (tabs)/          홈 · 기록 · 추천템 · 설정
│  ├─ onboarding.tsx   시작 안내 + 유의사항 동의 + 반려동물 등록
│  ├─ analyze.tsx      사진 분석 진행
│  ├─ record.tsx       울음소리 녹음(상황 선택 + 최대 10초)
│  ├─ result/[id].tsx  결과(기분·단서·건강 신호·고양이 통증 표정·케어 팁·추천 상품·공유)
│  └─ paywall.tsx      프리미엄 구독
├─ src/config/products.ts   추천 상품 목록 ← 쇼핑몰 링크는 여기서 관리
├─ src/locales/        한국어·영어·일본어 문구
├─ src/lib/            서버 통신, 결제, 광고, 저장, 상태 관리
│  └─ acoustics.ts     녹음 → 소리 특징·소리 그림 계산(기기 안에서)
├─ server/             AI 분석 서버(Cloudflare Workers + Claude API)
│  ├─ src/prompt.ts    사진 AI 분석 지시문 ← 고치고 배포하면 앱 업데이트 없이 반영
│  ├─ src/voicePrompt.ts 울음소리 AI 분석 지시문
│  └─ wrangler.toml    무료 횟수·한도·AI 모델 설정
└─ docs/               운영 문서
```

## 개발자용 빠른 실행
```bash
npm install
npx tsc --noEmit                 # 타입 검사
cd server && npm install && npm test   # 서버 단위 테스트
```
- 결제·광고 모듈이 들어 있어 **Expo Go 앱에서는 실행되지 않습니다.** 개발용 빌드(`eas build --profile development`)를 사용하세요.
- `.env`의 `EXPO_PUBLIC_API_URL`이 비어 있는 개발용 빌드는 **데모 모드**로 예시 결과를 보여 줍니다(AI 비용 없음).

## 울음소리 분석 동작 방식
Claude API는 오디오를 직접 받지 않습니다. 그래서 다음 순서로 처리합니다.
1. 휴대폰이 마이크 소리를 실시간으로 받아(expo-audio) 녹음 파일 없이 메모리에만 둡니다.
2. 기기 안에서 음높이, 길이, 반복 횟수, 크기, 맑은/거친 소리 정도, 골골송 같은 낮은 진동을 계산하고 소리 그림(멜 스펙트로그램)을 만듭니다(`src/lib/acoustics.ts`).
3. 숫자 특징과 소리 그림만 서버로 보냅니다. 서버가 소리 그림을 PNG로 그려 Claude에 함께 보냅니다.
4. Claude가 소리 종류(야옹·골골송·하악질·멍멍·낑낑 등), 기분, 컨디션, 원하는 것, 건강 신호를 추정합니다.
- 녹음이 너무 조용하면 서버로 보내지 않습니다(비용 0원).
- 정확도 한계: 사진보다 근거가 제한적이라 앱에 "참고용"과 "번역기가 아님"을 안내합니다.

## 데이터 처리 요약
- 사진은 분석 요청 때만 서버를 거쳐 Claude API(Anthropic)로 전송되며, 펫페이스 서버에는 저장하지 않습니다.
- 녹음 원본은 기기 밖으로 보내지 않습니다. 숫자 특징과 소리 그림만 전송합니다.
- 기록·사진·반려동물 정보는 사용자 기기에만 저장됩니다.
- 서버는 기기별 무료 횟수만 최대 48시간 동안 보관합니다.
